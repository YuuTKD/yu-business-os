# YU BusinessOS × TREE's Catering
## 広告費ゼロ集客OS：30日実装仕様書

作成日: 2026-07-27
対象プロジェクト: YU BusinessOS
実行エージェント: Claude Code

---

## 1. 目的

TREE's Cateringの完成済みLPを中核に、広告費を使わずに以下の無料チャネルから問い合わせと受注を生み出す。

1. 過去顧客・既存人脈
2. ゆうさんの既存事業（BAR、サロン、飲食店等）
3. レンタルスペース、BAR、結婚式二次会会場等との提携
4. Googleビジネスプロフィール
5. Instagram・LINE公式
6. 口コミ・紹介
7. SEO・事例コンテンツ

30日後の目標:

- 問い合わせ: 15件以上
- 受注: 3〜5件
- LP経由売上: 30万〜50万円
- 新規提携先: 5社
- Google口コミ: 10件以上
- ゆうさん本人の運用作業: 週30分以内

---

## 2. 絶対条件

- 広告費ゼロで開始する。
- 有料API、有料SaaS、新規課金ツールを導入しない。
- ゆうさんにDM送信、投稿作成、集計作業を恒常的に担当させない。
- 外部送信や公開変更は、承認なしで実行しない。
- 既存YU BusinessOSの技術スタック、設計規約、DB、認証方式を優先する。
- 新しい別アプリを乱立させず、既存OS内のケータリング事業モジュールとして実装する。
- 問い合わせ件数ではなく、受注売上・粗利・流入元を追跡する。
- 個人情報、APIキー、LINE・Google等の認証情報をリポジトリへ保存しない。

---

## 3. 既存商品の前提

TREE's Cateringには以下の販売材料がある。

- 企業懇親会、結婚式二次会、BAR周年、クラブ、女子会、誕生日等の13シーン別提案
- 1名1,500円、2,000円、3,000円以上の料金プラン
- 5万円、8万円、12万円のパーティープラン
- オードブルと設営付きケータリングの2商品
- 20〜120名規模、昼・夜・深夜対応
- 料理だけでなく設営、テーブル演出、撤収まで対応
- BARの1次会商品化、結婚式二次会・貸切プラン等のB2B提案資料

OS上では、低単価オードブルと高単価ケータリングを別商品として管理すること。

## 5. 無料集客OSの機能要件

### 5.1 集客先CRM

管理対象:

- 過去顧客
- 既存人脈
- 自社事業顧客
- レンタルスペース
- BAR・クラブ
- 結婚式二次会会場
- ホテル・ヴィラ
- イベント会社
- バルーン・装飾会社
- 撮影スタジオ
- 美容・ブライダル関係

必須項目:

- 名称
- 種別
- 会社・店舗名
- 担当者名
- メール
- 電話
- Instagram
- Webサイト
- エリア
- 接触元
- 優先度 A/B/C
- 見込み確度 0〜100
- 最終接触日
- 次回アクション日
- ステータス
- 使用テンプレート
- LP URL
- UTM URL
- 紹介者
- 備考

ステータス:

- `NEW`
- `READY_TO_CONTACT`
- `CONTACTED`
- `FOLLOW_UP_1`
- `FOLLOW_UP_2`
- `REPLIED`
- `MEETING`
- `PARTNER_LISTED`
- `INQUIRY`
- `QUOTED`
- `WON`
- `LOST`
- `DORMANT`

### 5.2 流入元管理

流入元コード:

- `existing_customer`
- `existing_network`
- `own_business`
- `partner_space`
- `partner_bar`
- `partner_wedding`
- `google_business`
- `instagram`
- `line`
- `referral`
- `organic_search`
- `other`

各問い合わせ・案件に以下を紐付ける。

- 初回流入元
- 最終接触流入元
- UTM source / medium / campaign / content
- LPバージョン
- 問い合わせ日
- 見積額
- 受注額
- 粗利額
- 失注理由

### 5.3 UTMリンク生成

入力:

- LPのベースURL
- source
- medium
- campaign
- content
- 提携先ID

出力:

- 完成URL
- コピー用テキスト
- QRコード生成用値（既存機能があればQR表示）

命名規則:

- 小文字英数字とアンダースコア
- 日本語・空白禁止
- 例: `partner_space`, `instagram_story`, `past_customer_line`

### 5.4 次アクション自動抽出

ダッシュボードに毎日表示する。

- 本日初回接触する相手
- 3日後フォロー対象
- 7日後フォロー対象
- 返信あり・未対応
- 見積提出後48時間経過
- 受注後口コミ依頼対象
- 受注後紹介依頼対象
- 提携掲載後30日間問い合わせゼロの提携先

ゆうさん向け表示は「承認待ち」と「重要判断」のみとする。

### 5.5 テンプレートライブラリ

用途別に保存・編集・コピーできること。

- 過去顧客へのLP案内
- 既存人脈への紹介依頼
- レンタルスペース提携
- BAR・クラブ提携
- 結婚式二次会会場提携
- ホテル・ヴィラ提携
- 1回目フォロー
- 2回目フォロー
- Google口コミ依頼
- 紹介依頼
- Instagram投稿
- Instagramストーリー
- Googleビジネスプロフィール投稿
- LINE配信

各テンプレートに以下を持たせる。

- 対象業態
- チャネル
- 使用目的
- 本文
- CTA
- LP URL差し込み位置
- 変数一覧
- 利用回数
- 返信率
- 受注件数

### 5.6 コンテンツ再利用管理

1案件の事例から以下を派生させる。

- Instagramフィード投稿
- Instagramストーリー
- Googleビジネスプロフィール投稿
- SEO事例ページ
- 提携営業用実績サマリー
- 口コミ依頼

事例必須項目:

- イベント種別
- 開催場所
- 人数
- 予算レンジ
- 主催者の目的
- 課題
- 提案内容
- メニュー
- 装飾
- 売上
- 原価
- 外注費
- 粗利
- Before / After画像
- 顧客コメント
- 公開許可

### 5.7 KPIダッシュボード

無料集客チャネル別に表示する。

- 接触件数
- 返信件数
- 返信率
- 問い合わせ件数
- 見積件数
- 受注件数
- 受注率
- 売上
- 粗利
- CAC（無料施策では人件費・外注費を含める場合に対応）
- 平均受注額
- 紹介件数
- 口コミ獲得数
- 提携先数
- 提携先別売上

30日KPI:

- 既存顧客・人脈への案内: 100件
- 提携候補への接触: 30社
- 提携掲載: 5社
- 口コミ依頼: 20件
- 口コミ獲得: 10件
- 投稿: 12本
- SEO・事例ページ: 4本
- 問い合わせ: 15件
- 受注: 3〜5件
- LP経由売上: 30万〜50万円

## 7. 30日運用スプリント

### Week 1: 基盤

- リポジトリ監査
- 集客先CRM
- ステータス
- 流入元
- UTM生成
- CSVテンプレート
- ダッシュボード最小版

完了条件:

- 100件の連絡先をCSVで投入可能
- 連絡先ごとの次回アクションを表示可能
- LP流入元をUTMで区別可能

### Week 2: 送信準備

- テンプレートライブラリ
- 変数差し込み
- コピー機能
- 1回目・2回目フォロー日程
- 口コミ・紹介依頼フロー

- スタッフが一覧から相手を選び、送る文章とURLを1クリックでコピーできる
- ゆうさんは文章を毎回作らない

### Week 3: コンテンツ資産化

- 事例登録
- 1案件5媒体展開チェックリスト
- SEO記事管理
- Instagram・Google投稿管理

完了条件:

- 1案件から5種類のコンテンツ制作タスクが自動作成される
- 公開許可のない画像・顧客情報は公開対象にならない

### Week 4: 集計と改善

- 流入元別KPI
- 提携先別売上
- 失注理由
- 30日レビュー画面
- 翌月の優先チャネル提案

完了条件:

- どの無料施策が問い合わせ、受注、粗利を生んだか分かる
- 翌月に止める施策と伸ばす施策を判断できる
